Этот репозиторий содержит актуальные списки серверов для программы **LSB (Launcher & Server Browser)**, предназначенной для игры Counter-Strike 1.6.

Он служит централизованным источником данных, который позволяет клиентам LSB всегда иметь доступ к свежему списку игровых серверов без необходимости ручного обновления.

## Содержимое репозитория

Репозиторий включает в себя два основных текстовых файла:

### ms.txt

Это основной файл со списком серверов. Он содержит адреса активных игровых серверов Counter-Strike 1.6 в формате IP:Порт.

- **Назначение:** Используется клиентами LSB для заполнения вкладки "Интернет" актуальными серверами.
- **Обновление:** Файл регулярно обновляется, чтобы добавлять новые серверы и удалять неработающие.

### blacklist.txt

Этот файл содержит список серверов, которые были исключены из основного списка.

- **Назначение:** Служит для фильтрации нежелательных, нестабильных, фейковых, без FastDL серверов, а также серверов-зеркал (Mirror). Это повышает качество основного списка, предоставляемого в `ms.txt`.
- **Обновление:** Файл обновляется после проверки Issue или Pull Request запросов. Также жалоб от сообщества ONGG.

## Внесение вклада

Этот репозиторий поддерживается сообществом для обеспечения актуальности списков серверов. Если вы хотите предложить изменения (например, добавить новый популярный сервер или сообщить о неработающем), вы можете открыть Issue или Pull Request в этом репозитории.

## Связь с LSB

Данный список серверов разработан для использования с программой **Launcher & Server Browser (LSB)**. Более подробную информацию о самой программе, её возможностях и настройке вы можете найти на официальной странице проекта.
